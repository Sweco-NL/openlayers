--- layout: example.html title: Topological Curve Drawing shortdesc: Draw curves with topological validation, boundary tracing and shared arc geometries. docs: > Demonstrates topology enforcement during curve drawing and editing.
  • Crossing prevention — clicks that would create edge crossings (self-intersections or overlaps) are rejected.
  • Boundary tracing — click on an existing CurvePolygon boundary to trace along it; the traced portion is reconstructed as actual arc sub-geometries (not tessellated approximations).
  • Shared boundaries — traced arcs are exact copies of the source feature's CircularString/CompoundCurve segments, ensuring zero-gap, database-quality topology.
  • Modify validation — editing a vertex that would create a self-intersection or overlap is automatically reverted.
  • Snapping — vertex, edge and intersection snapping ensures topologically correct adjacency.
Uses only built-in OpenLayers topology primitives (no JSTS). tags: "draw, topology, curve, curvepolygon, compoundcurve, circularstring, snap, trace, validation" ---
